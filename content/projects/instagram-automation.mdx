## Overview

Instagram Automation logs in to an Instagram account with the account's email and password, then acts on it with no one at the keyboard. Right now it listens to the DMs I configure and uploads the Instagram Reels that arrive in them.

I built it for personal use. It could run a bot, but that is not what it is for.

## How it works

The program runs on a regular computer, but it presents itself to Instagram as a phone. Some of the APIs it needs are ones only the mobile app calls, and Instagram answers them only for a phone. I collected those APIs by capturing the traffic from my own phone while I used the app.

You choose which users' DMs it listens to. When one of those conversations receives a Reel, the program uploads it.

Messages are encrypted with AES, using Instagram's public key and the user's data.

## Stack

TypeScript on Node.js. I'm building the front end in Flutter.

## Challenges

### Login

The first login request sends a public security key along with it. To get my request accepted, I had to retrace each step the app takes to build that request, until mine passed as a genuine login. That one detail took me two days.

### Looking human

Because the program acts on its own, Instagram often flags the connected account as a bot. I'm developing an AI that sends requests in a human pattern, so the account doesn't get flagged.

## What's next

The Flutter front end and the human-pattern request sender are both in progress.
