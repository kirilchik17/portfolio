## Overview

Watchdog was my first project, built when I started working at Infoneto at 17. It keeps a system made of several programs running.

## How it works

1. On its first run, you configure which programs it should watch.
2. It updates the Windows registry for its own use.
3. It then runs as a Windows service and monitors the configured programs.
4. When a program hits an error or freezes, Watchdog acts to get it running again.
