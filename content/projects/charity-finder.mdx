## Overview

Users enter their needs and situation, and the app looks up a charity that can help them.

## Data

The data comes from the official Israeli registry of non-profit organizations, collected with my [Web Scraper](/projects/web-scraper). The public version of that scraper reads each organization's GuideStar page and its Kol Zchut entry. For every organization it records the fields of activity, target groups, activity region, cost, and contact details, and writes them to CSV.

## Deployment

The test version is written in ASP.NET. It runs on Google Cloud Run as a Docker image and connects to a Google Cloud SQL database through a proxy.

## Challenges

### Information gathering

The first problem was gathering information about the charities. The registry has extensive data, but collecting and analyzing it took a long time. To speed it up I took a deep dive into the site's architecture and its outgoing requests. I found several vulnerabilities and reported them to the Israeli Department of Cyber Security. Some of the minor ones let me gather the data much more efficiently.

### Docker and Cloud SQL

The other challenge was connecting the Docker image to Google Cloud SQL, mainly because the service is poorly documented.

## What's next
